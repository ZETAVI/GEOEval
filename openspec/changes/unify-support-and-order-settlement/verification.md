# 验收计划与当前证据

当前状态：提案与架构复盘已形成；业务代码、数据库迁移、运行验证尚未完成。本文件不得作为运行通过证据。

| 场景 | 最小证据 | 当前结果 |
| --- | --- | --- |
| 创建订单/充值/普通工单，复制 ID 防越权 | API + 真实浏览器 | Not run |
| 普通工单并发领取、订单改派撤权 | PostgreSQL 并发事务 | Not run |
| 多次沟通、统一总额 100→150、不即时到账 | API + 原流水不变 | Not run |
| 客户只有统一待退文案与到账后提示 | UI + 浏览器 | Not run |
| 完成/关闭首次时间不重置 | 单元 + 数据库 | Not run |
| 截止前后、重复提交、一次机会不恢复 | 可控时钟 + 数据库竞争 | Not run |
| 正额终止先结束发布，不产生循环 | 订单/工单/结算串联测试 | Not run |
| 已受理工单跨期阻止结算，最后处理后唤醒 | 集成 + Worker | Not run |
| 正额一次退点、零额有凭据但无零流水 | 数据库约束 + 查询 | Not run |
| 账本失败整笔回滚，崩溃后恢复，重复 Worker | 注入失败 + 进程重启 | Not run |
| 原来源比例与 Recharge 预留容量 | 复用 + 扩展原退点测试 | Not run |
| 旧待退义务和已退历史不丢失/重退 | 备份、升级、恢复演练 | Not run |
| 生成契约、类型、构建和当前 spec 对账 | 项目检查/CI | Not run |

并发时间特别检查：先开始事务但等待锁至截止后的请求，不能凭 CURRENT_TIMESTAMP 获得过期申诉资格。不同订单的普通处理不受全局锁串行阻塞。工作批次中长期待协商订单不能饿死其他已可结算订单。

提案检查：审批方向与最新用户文案一致，旧立即退点方向被替代；Support、Delivery、Commerce、Recharge 无重复资金 owner。正式实现必须在同一 owning Issue 下推进，只有完整验收与当前态对账后才可关闭。
